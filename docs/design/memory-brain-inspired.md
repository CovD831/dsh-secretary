# 仿人脑记忆：可借的效率、人格与不可借的失真

> 2026-11-22；限时探索，不是新增架构或一期功能提案。外部来源于当日经 PubMed、Crossref、arXiv 或项目官方 README 核实；检索接口当时不可用，未做全文系统综述。下文「事实」指来源或既有设计明载，「推断」指工程建议。异步巩固的既有结论见 `memory-async-consolidation.md`，此处只补脑机制与取舍。

## 1. 先定边界：借计算原则，不借生理外形

**事实**：秘书的真实感由连续性提供，而假记忆比没记忆更伤人（`01-ORIGIN-AND-EVOLUTION.md` §4.8）；一期阶段 4 只做「Markdown 实体页 + git、唯一写入者、纠正/偏好/否决、带出处、新会话注入」，M2–M6、索引、embedding 均不做（PRD §2.1、§4、§8）。因此本文不把「脑科学」当成提前解禁 M2–M6 的理由。
**推断**：值得模仿的是容量预算、快慢分工、按线索调取、来源意识和重要性调度；不值得模仿的是读后改写原文、把推断当亲历、自动抹平冲突、时间到即忘。「像人」应表现为更少重复打扰和稳定连续性，不是偶尔自信地讲错过去。

## 2. 九项机制：神经/认知事实 → 我方映射 → 收益与风险

| 人脑机制（2–3 句事实性说明） | 我方映射（推断） | 真实感/活人感贡献 | 真实性风险与硬边界 |
|---|---|---|---|
| **工作记忆容量有限**：Cowan 在控制复述、再组块等条件后，将核心短时容量估为约 4 个组块，而不是机械套用 7±2；这描述特定条件下的注意焦点，不是一切任务的固定槽位数。[S1] | 常驻注入只放当前需要的 M2/M3 活跃摘要，硬预算、超限报错；其他按 ticket/workspace 检索，M6 一次只呈一待裁。 | 不淹没老板、不每轮复述生平，回应聚焦当前事。 | 容量小会漏关键上下文；不得静默截断，查不到须说「未检索到」，必要时回 M0。 |
| **情景、语义、程序记忆分工**：记忆不是单一仓库；陈述性记忆覆盖事实与事件，非陈述性记忆包含技能/习惯等不同系统。三分法是功能抽象，不应被误解为三个彼此孤立脑区。[S2] | M0 保留事件原文，M1–M4 保存带出处事实/模式，M5 只存经裁决的 gate/skill；程序记忆晋升链与事实记忆分开。 | 秘书既记得发生过什么，也知道老板喜欢怎样协作；习惯稳定而非每次现学。 | 把一次事件泛化成偏好、把参考记忆当执行指令；M4 不许单次直写，注入须标 notes not instructions。 |
| **互补学习系统（CLS）**：海马支持快速、特异的情景学习，新皮层靠渐进、交错学习提取结构；单一分布式系统顺序学习会发生灾难性干扰。[S3] | M0/M1 快速记录具体证据；M4 只由跨工作区巩固器提候选，经评估/人裁才晋升，M5 再走独立晋升梯。 | 能立刻记住一句纠正，同时不因一句话就改变人格。 | 快层错误会污染慢层，慢层抽象会丢失反例；原文不删、候选带 Seen 与出处、冲突待裁。 |
| **睡眠巩固**：睡眠参与记忆稳定与系统级整合，不是简单「夜间压缩全部日志」；具体效应依任务与条件，不能推导出任意 LLM 做梦都有益。[S4] | 只借「前后台分工」：闲时巩固器仍是提议者，逐条 patch + 证据 + 版本，前台唯一写入者不变。 | 后台变有序，前台不被记忆维护阻塞。 | 摘要替代原文、同簇误并、旧错误再加工；一期不运行做梦，后续须冻结回放证明零新增假回忆。 |
| **再巩固**：已巩固记忆在再激活后可短暂不稳定，需要再次稳定；这为更新提供机会，也使记忆在回忆/更新窗口中被扭曲。[S5] | **只借「新证据可更新现行视图」**：用户新直述立即使旧条目失效；不模仿读后改原迹，git 与 M0 保留不可变历史。 | 改口后秘书跟得上，不抱着旧偏好不放。 | 回忆时把当前解释写回过去、形成假记忆；读取绝不产生写权限，supersedes/tombstone 不物理覆盖。 |
| **遗忘与干扰**：遗忘不只是被动时间衰减，相似线索竞争会造成干扰；但强度降低或提取失败不等于原事件从未存在。[S6] | 降低旧派生摘要的默认可见性、按任务与现行状态检索；canonical 原文保留，明确作废才 tombstone，M6 防重复问。 | 不被陈旧细节缠住，像人一样抓当前重点。 | 自动衰减把真事忘掉，或相似人物/项目串台；不以「时间久」删除事实，scope 隔离，未命中回查 M0。 |
| **来源监控**：人会判断一段内容来自感知、想象还是他人；来源归因可出错，「内容鲜活/眼熟」不能保证「从哪知道」判断正确。[S7] | 每条 M1–M4 带 `source_type/source_ref/author/taint/confidence`，推断与用户直述分栏；同级冲突进 M6。 | 秘书能说「你上周在 X 里定的」，而不是无根的「我一直知道」。 | 把模型推断、网页或 worker 汇报冒充老板直述；无出处不进长期层，来源存在仍须核对结论是否被原文支持。 |
| **提取线索与情境依赖**：编码特异性强调提取效果取决于线索与编码时情境的匹配；同一个事实不是所有场合都同等容易想起。[S8] | 以 person/project/ticket/decision 等稳定实体线索检索；保留时间、workspace 与来源语境，注入当前工作区相关页。 | 在对的时机自然接续，而非机械报出全部记忆。 | 情境错配导致张冠李戴，过度 personalization 形成滤镜；检索留痕，允许展开原文与跨 scope 纠错。 |
| **情绪显著性加权**：情绪唤醒可通过杏仁核等调制长期记忆巩固，显著事件常获得不同巩固优先级；但「情绪强」不等于「细节更真」。[S9] | 不推断老板情绪；仅用可观察信号（明确否决、反复纠正、阻塞、人裁）作为待办/复核优先级，事实真伪与优先级分开。 | 对痛点和雷区更敏感，少在相同地方惹恼老板。 | 把语气当事实、把高显著性当高可信；重要度只调注意力，不改 confidence，不自动写 M2/M4。 |

## 3. 明确取舍：哪些「像人」要，哪些「像人」坚决不要

| 取舍 | 决定（推断） | 理由 |
|---|---|---|
| 快记 + 慢抽象 | **要**：M0/M1 快记，M4/M5 慢晋升 | 一次纠正立刻生效，人格与规则却不随单事件漂移。 |
| 有限注意 + 线索提取 | **要**：小注入、按当前上下文取、M0 兜底 | 高效来自少而准，不来自把所有过去塞给模型。 |
| 有来源的更新 | **要**：现行事实可变，历史不可改 | 能改口又能审计；「读」与「写」物理分权。 |
| 默认降低旧信息显著性 | **有限要**：只降派生注入/排序，不删 canonical | 获得遗忘的抗干扰收益，不承受事实消失。 |
| 显著性调度 | **有限要**：可观察纠正/否决/阻塞提优先级 | 提供人格连续性；绝不从文本推断情绪或把重要性当真实性。 |
| 读后改写、来源混淆、冲突静默抹平 | **拒绝** | 这是人脑效率的代价，不是活人感；我们的「更新」是新增版本链，不是重写回忆。 |
| 自信补全空白、把推断说成亲历 | **拒绝** | 人格口吻可以自然，证据状态必须裸露：记得/推断/未查到三分。 |

**一句话（推断）**：让秘书像人一样「有重点、有连续性、知道何时该查证」，但不要像人一样「把重构当回放」。真实感由稳定行为与诚实的不确定性共同产生，而不是由拟人化叙事掩盖证据缺口。

## 4. 仿脑/分层项目核查（只作参照，不作真实性背书）

- **HippoRAG / HippoRAG 2（已核实存在）**：Gutiérrez 等，NeurIPS 2024 / ICML 2025；[官方仓库](https://github.com/OSU-NLP-Group/HippoRAG)、[论文摘要](https://arxiv.org/abs/2405.14831)。以 LLM、知识图谱、Personalized PageRank 模拟新皮层与海马的不同角色，重点是关联检索。README 有 `source_id/metadata`、删除和增量索引；未看到原文不可变、逐条事实证据门或防假巩固，借关联思想即可。
- **A-MEM（已核实存在，但不宣称具体仿脑机制）**：Xu 等，2025，[仓库](https://github.com/agiresearch/A-mem)、[摘要](https://arxiv.org/abs/2502.12110)。明确仿的是 **Zettelkasten** 动态索引/连接，新记忆可演化旧记忆上下文；不是 CLS/海马模型。演化可能重写表征，页面未见逐条出处、不可变原文或专门真实性保护，不能直接接 canonical。
- **MemoryOS（已核实存在，仿操作系统而非人脑）**：Kang 等，2025，[仓库](https://github.com/BAI-LAB/MemoryOS)、[摘要](https://arxiv.org/abs/2506.06326)。短/中/长期分层、对话链 FIFO、分段页组织与层级更新。页面未见逐条溯源或防假记忆承诺；分层可参照，FIFO 不等于应遗忘事实。

## 5. 建议（均为推断，按现有 PRD 收敛）

### 阶段 4：最简记忆，最多三件

1. **把来源意识做成 UI/协议，而非新记忆层**：注入与回答区分「你明确说过 / 系统推断 / 未查到」，每条可展开到 M0；一期仍只收用户纠正、偏好、否决，推断不进长期层。
2. **采用「小注入 + 明确未命中」**：注入硬预算、超限报错；查不到不补全，必要时读原文；验收除「不再重复问」，增加「无材料时不虚构」与「改口后新会话采用新版」红绿 fixture。
3. **读取零写副作用**：回忆只读，纠正通过唯一入口新增 supersede/tombstone；留存 `memory.proposed/accepted/rejected` 与稳定游标即可，不加情绪分、衰减分、访问频率或做梦。

### 后续：以狗粮数据逐项解禁，最多三件

1. **先做线索检索，再做慢抽象**：阶段 5 后用重复提问/漏取记录选择实体、workspace、时间等线索；关联图、向量与 HippoRAG 式检索须各自回放证明收益，不因「仿脑」捆绑上线。
2. **CLS 只落成晋升纪律**：具体事件快速入 M0/M1，跨工作区模式须多次异源证据、人裁/评估晋升；始终保留反例与原文，禁止慢层反向覆盖快层。
3. **显著性只优化注意力**：用明确否决、反复纠正、阻塞等事件信号排序 M6 和复核队列，独立于事实置信度；以重复打扰率、假回忆数、被纠正条数/周评估，量不到收敛收益即撤。
